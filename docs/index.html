常见问题

FAQ

01Exero 是免费的吗？
是，Exero 完全开源免费，代码托管在 GitHub，欢迎 Star 与贡献。
02支持哪些 Windows 版本？
Windows 10 及以上（x64），基于 Tauri v2 构建，体积小、资源占用低。
03需要联网吗？
核心功能完全离线可用。仅扩展市场下载与自动更新需要联网，且支持镜像加速与离线兜底。
04数据存在哪里？会被上传吗？
全部存储在本地 SQLite 数据库，启用 WAL 模式，不会上传任何数据。
05不会写代码也能用吗？
可以。可视化编辑器拖拽积木连线即可组合工作流，无需写一行代码。Lua 脚本面向进阶用户，非必需。
